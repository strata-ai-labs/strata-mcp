# strata-mcp — retired

**This repo is retired (2026-08-05). Everything moved to
[strata-agent-skills](https://github.com/stratalab/strata-agent-skills)** — the
consolidated agent-facing surface: skills, the `npx strata init` on-ramp, and MCP
setup, in one repo.

The Strata MCP server itself lives in
[strata-core](https://github.com/stratalab/strata-core) as `strata mcp serve`,
inside the CLI binary — one canonical implementation.

History of the pre-V1 standalone server remains in this repo's git history.
